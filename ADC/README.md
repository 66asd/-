# 双 ADC 动态采样与 page3 示波显示

STM32F103C8T6，ADC1/ADC2 规则组同步，TIM3 TRGO 触发，DMA1 Channel1 32 位循环搬运。
从 50 Hz 起自动选择采样档位，最高每路 500 kS/s。120 kHz 是期望使用范围，不是软件截止频率。
HMI 保持原文件不变。频率、交流 RMS、VPP、采样策略、采集、波形、屏幕协议各自独立模块。
当前固件参考电压为 **3190 mV**：用户实测3.3V引脚为3.19V，并确认VDDA与该电源相连。
此值用于RMS/VPP的码值到电压换算；VOFA的原始ADC码不受影响。更换电源后应复测VDDA。

## 打开与接线

打开 `MDK-ARM/ADC_1k_20k.uvprojx`（低采样率）或 `MDK-ARM/ADC_1k_100k.uvprojx`（高采样率）。
两个工程共享全部源码，编译宏 SCOPE_TARGET_POINTS 分别为16/64，独立输出 AXF 到 `build/ADC_1k_20k/`、`build/ADC_1k_100k/`。
`MDK-ARM/ADC.uvprojx` 保留低档默认策略。三个工程均关闭 HEX 输出，后续禁止生成 HEX。
J-Link 已配置为调试/下载驱动，新工程附有最小 `.uvoptx`，不绑定探针序列号。
Keil 中按 F7 编译，确认 Debug 页为 J-LINK / J-TRACE Cortex，Settings 中选择自己的 J-Link、SWD。
确认 Utilities 使用目标调试驱动，再点击 Download 下载；复位运行。当前任务未自动烧录硬件。

## 本次修正的无显示路径

- 不再要求“两路波形都完成”才刷新数字；启动时即具备可显示的中线和无效读数。
- 开机等待约 800 ms 后主动执行 `page 3`，无需先收到 sendme 回包才能开始输出。
- 采用普通 ASCII `add` 指令分批绘制，不进入 addt 透传，不等待 FE/FD。
  屏幕没有 RX 回包时仍可输出，按钮操作仍需要屏 TX→PA10 的接收线路正常。
- 一次最多发送四对波形点，UART 中断非阻塞发送，保持发送缓冲区在完成中断前不变。
- 数值先发，再画波形；停止时只需等在途小包结束，不必等待整幅波形。
- UART 发送超过 200 ms 未完成时，端口执行中止与重同步，避免永久卡在发送态。
- ADC 初始化失败保留串口调度，不再直接让整机停进 Error_Handler。
- 当前 .ioc 和 tim.c 已同步为 ARR=143；运行时不再用旧的 200 kS/s 常量拒绝启动。

这些是已经通过软件测试修正的故障路径；未连接实体开发板，不能据此断言实机故障只来自其中某一项。

普通 add 在 115200 波特率下整帧约需 0.6～0.8 秒，约 1～2 帧/秒。
采用该兼容模式优先保证稳定显示；它不是将全部 ADC 数据实时上传屏幕。
开机主动进 page3 是 MCU 运行时命令，没有更改 HMI 文件的默认开机脚本。

## 动态采样档位

两 ADC 同时采样，共用一个 TIM3，所以**硬件采样率以两路中较高频率为准**。
若两路分别为 50 Hz、120 kHz，硬件均使用 500 kS/s，低频一路在组分析帧时独立选点到约 5 kS/s。
不能用同一个触发源让两个 ADC 分别拥有独立的硬件采样率。

稳定信号的名义目标是每周期约 16 点；默认 1 kHz 先降到 20 kS/s（每周期20点），选择不低于目标的离散档位：

| 较高一路频率（名义分档） | 每路硬件采样率 | 高档降入该档时的频率上限 | TIM3 ARR |
|---|---:|---:|---:|
| 50～312.5 Hz | 5 kS/s | 281.25 Hz | 14399 |
| 312.5～625 Hz | 10 kS/s | 562.5 Hz | 7199 |
| 625～1250 Hz | 20 kS/s | 1125 Hz | 3599 |
| 1250～3125 Hz | 50 kS/s | 2812.5 Hz | 1439 |
| 3125～6250 Hz | 100 kS/s | 5625 Hz | 719 |
| 6250～12500 Hz | 200 kS/s | 11250 Hz | 359 |
| 高于12500 Hz | 500 kS/s | 不再升档 | 143 |

此表给出升档/目标分档边界。降档保留 10% 频率余量，并要求候选档位稳定 300 ms，
因此临界频率可能留在较高一档，而不会来回切换。无信号或直流可降到最低档。

例如 50 Hz 在最低档每周期约 100 点；1 kHz 在20 kS/s档约20点；10 kHz在200 kS/s档约20点；
40 kHz 约 12.5 点；120 kHz 约 4.17 点。硬件上限限制了高频段的点数，软件无法补出真实采样。

搜索策略：

1. 启动先使用 500 kS/s，高速帧优先识别高频信号。
2. 对尚未识别的低频通道，逐级扩大采样间隔获取更长时间跨度；避免只观察 2 ms 就判断 50 Hz 不存在。
3. 已锁定后按较高频率选择硬件档位，每路分析帧独立选择间隔。
4. 每隔约 1 秒以及点击自动设置时，重新以 500 kS/s 获取直接采样探测帧。
   探测短到不足以识别低频时，保留已有的可信低频结果。
5. 切换时停止 TIM3 和 ADC/DMA、更新 PSC/ARR 并清理旧标志，重新设置双 ADC 同步模式，
   再启动 DMA 和定时器。切换前后的数据不拼成一帧。

搜索间隔在切换硬件档位后也会重新限制，使有效分析采样率不低于5 kS/s，支持无信号启动后再接入50 Hz。
周期性高速探测用于从低档恢复高频，频率突变后可能需要约 1 秒再加捕获/分析时间重新锁定。
仅根据低速采样数据无法排除混叠，不能保证突变瞬间绝不发生欠采样。

## 处理结构与时序

- DMA 为 1024 个 32 位字，半块 512 对；500 kS/s 时半块完成间隔 1.024 ms。
- ISR 只标记完成序号；主循环复制完整半块，复制中跨界的副本作废。
- 每路保留 1024 个 16 位分析采样点。按选点间隔直接跳到所需索引，减少处理负担。
- 帧完成后保持其不可变，分批执行矩统计、周期估计、正弦拟合和波形映射。
  一次只做少量分析工作，期间继续处理串口和 DMA。
- DMA 始终循环，分析以连续采样帧为单位，帧之间允许空隙；这是周期信号测量，不是无损全量录波。
- 意外丢半块时只丢弃未完成的捕获帧，保留最后可显示结果，避免不断重置所有状态导致整页无输出。

12 MHz ADC 时钟、7.5 cycles 采样，转换约 1.67 μs；500 kS/s 的触发周期是 2 μs。
ADC1 触发仍为 TIM3 TRGO，ADC2 保持 Software Start；Scan/Continuous/Discontinuous 关闭。
ADC1_DR 低 16 位为 ADC1，高 16 位为 ADC2，分别取低 12 位。
每次启动先恢复双模式，再执行 `HAL_ADC_Start(&hadc2)` 武装从机，最后启动主 ADC DMA 和 TIM3。
本工程 HAL_ADC_Init 实际未置 ADC2 EXTTRIG，而 MultiModeStart_DMA 也不替从机置位；
旧代码因此可能出现 ADC1 正常、ADC2 不转换。本次使用 HAL_ADC_Start 的从机路径补齐使能，不产生从机独立 SWSTART。
F1 HAL 的 MultiModeStop_DMA 会清除 DUALMOD，切档时已显式恢复同步模式。

## 算法模块

| 文件 | 职责 |
|---|---|
| scope_acquisition.c | 校准、动态 TIM3/双 ADC DMA、完整半块和错误标记 |
| sample_rate.c | 七档选择、双路较高频率、降档余量和保持时间 |
| measure_frequency.c | 滞回过零、插值、多周期平均、孤立漏周期与频率突变 |
| measure_rms.c | 64 位矩统计、整周期优先、交流与总 RMS |
| measure_vpp.c | 单码精度尾部分位数、小信号周期平均、拟合幅度合理性校验 |
| sine_fit.c | 两遍正弦最小二乘、残差判断及峰值漏采修正 |
| scope_waveform.c | 上升沿对齐、约四周期、纵向缩放、线性插值 |
| hmi_protocol.c / hmi_uart.c | HMI 字段、ASCII 波形、按钮和异步 UART |
| scope_app.c | 组帧、分批计算、动态采样和独立 UI 调度 |

频率、RMS 和拟合均使用该帧的**实际有效采样率**，不继续按固定 200 kS/s 解释数据。
频率没有 120 kHz 的软件截止；只有低频可信度和接近有效采样率奈奎斯特边界的检查。
无法可信估计时频率为 `--`，仍绘制采集到的真实帧，而不是完全不显示。

交流 RMS = sqrt(E[V²] - E[V]²)。用 64 位累加并优先选窗口内整周期，先在整数域扣掉直流能量。
VPP默认使用0.2%～99.8%位置的实际样本差，保留单个ADC码精度；不再按16码分桶。
小信号在周期数与采样点数足够时，使用相位对齐、剔除孤立极值后的周期平均波形测VPP。
满足正弦残差、剔除比例条件时，以 2*sqrt(a²+b²) 修正采样点落不到真实峰值的低估。
四点左右的高频数据不能可靠区分所有波形，拟合只在模型成立时有意义。
新增采样几何约束：拟合 VPP 与统计包络的比例不能超过 `1/cos(pi*f/fs)+0.03`，
且不能小于包络的90%。例如1 kHz/20 kS/s时上限约1.0425，不接受1.251倍的异常拟合放大。
没有将所有读数固定乘以1/1.251，这样的单点缩放会掩盖尚未确认的比例误差。

若输入为 0.6～2.7 V 的理想正弦：偏置 1.65 V，VPP=2.1 V，交流 RMS 约 0.742 V。
将实际 VDDA 毫伏数填入 scope_config.h 的 SCOPE_REFERENCE_MV，默认 3300。

## 使用 VOFA+ 核验 ADC1 原始数据

1. 断开串口屏的TX/RX，使用3.3 V逻辑的USB转TTL模块连接电脑：模块RX接PA9，模块TX接PA10，GND共地。
   J-Link继续用于下载；电脑接收数据需要USB串口通道。板子按原方式供电。
2. 打开VOFA+，选USB串口的COM号，**115200、8N1、无流控**，协议引擎选 **JustFloat**。
3. 以ASCII发送四个字符 `VOFA`（不带引号，不要求回车；十六进制为 `56 4F 46 41`）。
   上电默认仍是屏幕模式，开始核验前需发送此命令；此后USART1只输出JustFloat，不夹杂屏幕指令。
4. 添加波形控件，**只勾选通道0**，其他三个通道作为元数据查看，避免500000等数值压缩波形纵轴。
   Y轴先设0～4095，横轴先查看512个点；接近段边界时停止并选择同一段内的数据。
5. 核验完成后发送 `HMI!`（`48 4D 49 21`），再断开USB串口TX/RX，接回屏幕；也可复位后接回屏幕。

| VOFA通道 | 含义 | 单位/范围 |
|---|---|---|
| 0 | ADC1原始12位码值 | 0～4095，整数用float精确传输 |
| 1 | 本段真实硬件采样率 | samples/s，5000～500000 |
| 2 | 采集段编号 | 1起递增，24位循环；同一段保持不变 |
| 3 | 段内点序号 | 0～511，每段重新从0开始 |

数据直接取自通过完整性校验的DMA半块的低16位，保留低12位ADC码；
位于抽点、去直流、RMS/VPP、拟合和屏幕像素映射之前。不发送算法重建的正弦，也不乘任何幅度修正系数。
每段都是同一硬件采样率下512个连续点，发送期间原始段缓存不变，ADC和测量算法继续运行。

协议按[VOFA+官方JustFloat定义](https://www.vofa.plus/docs/learning/dataengines/justfloat/)实现：
每点4个小端float（原始码、采样率、段编号、点序号），末尾 `00 00 80 7F`，共20字节。
进入模式先发送独立帧尾，清除此前屏幕ASCII字节对接收解析的影响。

**这是分段核验，不是全速连续传输。** 115200波特率理论上仅约576点/秒，每段512点发送约0.89秒。
发送间隔中未保留的ADC采样不会补点；相邻采集段之间有时间空隙，VOFA普通波形图可能把边界连成直线。
需根据通道2区分采集段，按通道3定位段内数据；不得跨段计算周期或FFT。
同段内点间隔为 `1/通道1`，与电脑收到数据的时间间隔不同。VOFA的默认“采样率”若用于频谱/时间轴，
应手动设为本段通道1的数值；切换采样率后重新设置。

1 kHz低档稳定段通常为20 kS/s，512点覆盖25.6个周期；高档100 kS/s时覆盖5.12个周期。
周期探测段可能显示500 kS/s，512点只有1.024个1 kHz周期，频率/FFT检查请优先选稳定档位。
输入改变或另一路频率较高时，以通道1的实际值为准。原始缓冲区在不同档位之间不会混用。

将VOFA数据导出后，以同段通道0核验原始波形：`电压 = 原始码 × 实测VDDA / 4095`。
若VDDA=3.3 V、PA0引脚为1 Vpp，应有约1241码的幅度范围；噪声尖峰需单独辨认。
若原始码本身约1552码，则1.251 V来自采集/参考比例；若原始码幅度正常而屏上仍偏高，继续定位算法/显示链路。
原始码不能证明VDDA恰好为3.3 V，电压核验应使用实测参考电压。

Keil可观察 `g_vofa_diagnostics`：enabled、sample_rate_hz、segment_id、samples_sent、segments_sent、errors。
发送停滞超过200 ms会中止本段并重新同步；不拼接残缺段冒充完整段。

## 真实CSV末段的VPP复算与修正

用户提供的 `vofa+.csv` 最后采集段为I2=3408，Fs=20000 S/s，I3=0～261，共262点。
末段在文件尾被截断，不能与前一段拼成连续波形。以下结果只使用这262点，参考电压按实测3.19V。

| 方法 | 结果 |
|---|---:|
| 原始码最小/最大 | 1424 / 2768 |
| 最大减最小 | 1.046974 Vpp |
| 原有直方图稳健包络 | 1.044415 Vpp |
| 修正后实际C代码正弦拟合及选择 | 0.980642 Vpp |
| 独立最小二乘正弦拟合（交叉验证） | 0.980578 Vpp |
| 实际C代码测频 | 999.884766 Hz |
| 全部262点去直流RMS | 0.347674 V |

旧算法的正弦残差能量门限为0.15%，实际C重放得到约0.395%，因此拒绝正弦模型，回退到带噪包络。
将门限调整为0.5%，保留两遍拟合、异常点比例限制和幅度交叉检查。
方波、三角波、20%削顶正弦、10%三次谐波的正弦模型拒绝测试仍必须通过。
这是容许实测噪声的识别门限修正，不是用任意增益把所有波形修成1V。

`Tests/captured_sine.inc` 保留最后完整段3407和最后部分段3408，作为两个独立真实采样回归用例；
不将分段数据拼接。测试先在旧实现上复现失败，随后验证修正实现。
段3407的新算法结果为0.987085 Vpp，说明不同采集段仍有起伏。真实数据拟合结果不强制等于输入设定值。

仅将参考电压从3.3V改为3.19V，原屏显1.161V只会降为1.1223V。
所提供的262点不是屏幕当时使用的1024点分析帧，尚未完整复现1.161V；本次确认并修正的是参考电压配置和拟合拒绝问题。
烧录更新后需观察屏显是否接近真实数据的约0.98～0.99V，并继续核对PA0实际幅度与供电噪声。

## 50～100 mVpp小信号及动态ADC采样时间

实测VDDA=3.19V时，1个ADC码约0.779mV，50/100mVpp分别约64/128码。
旧`x >> 4`只是分桶索引，桶内sum仍保留原始码；问题是分位处用桶均值代替真实样本。
回归已复现：2040～2103的63码范围被旧算法算成56码。现移除幅值分桶，精确保留两端各32个样本，
1024点帧每端剔除2点，直接取真实次序统计量；内存也较旧直方图减少。

对稳健包络不超过256码（约199mV）的有效周期信号，若帧内至少8个周期、每周期至少8点，
按频率把多个周期对齐到最多32个相位位置；每个相位剔除一个最大/最小值后平均，再求平均波形的峰峰值。
在对齐前，用前后半帧各自去直流后的基波相位变化细化频率，避免噪声造成的过零时间误差展宽相位。
这样保留方波、三角波的形状，不要求噪声信号必须通过严格正弦识别，也不改VOFA原始数据。
孤立满量程/零码尖峰测试包含在回归内。已有有效幅度时，周期数不足8周期的500kS/s探测短帧保留此前幅度结果，
对小/大信号都保护，避免每秒探测时退回噪声包络或短窗拟合抬高显示；频率探测仍更新。
新幅度在随后正常分析帧中更新，高频探测帧周期数足够时也可更新。

相位平均测量的是稳定周期波形，不能保留单次瞬态；频率不准会导致相位展宽。
在50Hz端通常约10周期/帧；在高频每周期少于8点时，此方法不启用，回退到原有拟合/稳健包络。
20点/周期对三角波尖顶仍可能漏采，不能将正弦精度承诺到所有波形和所有频率。

软件测试条件：1kHz、3.19V参考；50/100mV正弦叠加137Hz、20码幅度干扰和±3码噪声，
另加单点4095/0尖峰，扫描5个初相；两套硬件采样率20/100kS/s。纯算法结果约49～51mV和99～101mV。
双通道应用同时运行50/100mV、周期探测和HMI发送，检查稳态25个显示时刻。
仿真显示在50mV与100mV附近波动数mV；精确范围由当前测试脚本输出，此处读数经过屏幕的1mV显示舍入。
这些是实际C代码的仿真，不是用户当前100mV的实测CSV；实机115～136mV问题仍需烧录后对照新数据核验。

动态改变的是**采样保持时间Ts**，逐次比较的12.5个ADC时钟保持不变。
只有有效测量通道均低于150mV时才请求长采样；存在大信号时保持7.5周期。
已进入长采样时使用200mV退出门限，避免档位抖动。悬空通道可能被识别为小信号，但其请求不能改变大信号通道的采样时间。
两路ADC同时采用相同Ts，停定时器和ADC后再配置，重启时清除部分帧，避免混合不同采样条件或引入两路采样窗口差异。
若只有一路是小信号、另一路频率很高，仍由共同硬件采样率约束Ts，不降低采样率迁就Ts。

| 每路采样率 | 小信号Ts（ADC周期） | Ts时间（12MHz） | Ts+12.5总转换时间 |
|---|---:|---:|---:|
| 5/10/20 kS/s | 239.5 | 19.958µs | 21.000µs |
| 50/100 kS/s | 71.5 | 5.958µs | 7.000µs |
| 200 kS/s | 41.5 | 3.458µs | 4.500µs |
| 500 kS/s | 7.5 | 0.625µs | 1.667µs |

非小信号保持7.5周期；18组采集测试校验所有档位的Ts、双路一致性及额外3个ADC周期的触发时序余量。
Keil可观察`adc_sample_cycles_x2`（479=239.5周期），以及`vpp_used_cycle[2]`、`vpp_cycle_counts[2]`。
对于1kHz低档20kS/s，小信号应看到479；高档100kS/s应看到143。

延长Ts主要改善高源阻抗下采样电容的建立；不能提高12位量化分辨率，也不等于硬件对输入做长时间平均。
低阻信号发生器直接输入时，单纯延长Ts未必明显改善噪声；50mV高精度测量还取决于供电、参考噪声、接地和模拟增益。
依据：[ST数据手册ADC时序](https://www.st.com/resource/en/datasheet/stm32f103c8.pdf)、
[ST AN2834 ADC精度](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf)。

## 1V与悬空通道的隔离回归

优化小信号时，正弦拟合公式、0.5%残差门限及3190mV参考参数没有改动。
共享的尾部包络由桶均值改为实际样本，提供的旧1V末段由1.044415变为1.046974V（包络差约2.6mV）；
其拟合及最终选择仍为0.980642V，不能据此完整复现用户新报的持续1.040V。

确认上一版有两处跨范围影响：任一路小信号会申请两路共同长采样，且短探测帧保持只针对小信号。
现改为大信号阻止共同长采样，并将短探测帧幅度保持应用到所有已稳定测量的幅度。
新增1kHz/1Vpp主通道叠加40码干扰、另一路只有20码周期拾取噪声的应用测试，检查25个显示时刻；
必须保持短采样且主通道幅度在1V附近。此噪声替身验证软件策略，不能代替真实悬空引脚的电气测量。
本次83组回归中，1V显示低档为1000mV，高档为1001～1002mV；50/100mV回归也通过。

若实机仍持续1.040V，先读`g_scope_diagnostics.adc_sample_cycles_x2`（大信号应为15），
再读对应通道`vpp_used_fit`、`vpp_fit_valid`、`vpp_fit_residual_ratio`、`vpp_raw_counts`与`vpp_fit_counts`，
区分是否回退包络、拟合本身偏高，或码值/参考换算偏差。未使用的PA1可接地后作对照。
本次未对实际1.040V采样帧做重放，不能宣称已定位全部40mV偏差。

## 备份上传次数

按2026-11-15用户新规则：本地保留前后版本，每次任务仅在完成时尝试一次远端上传，限时20秒。
失败后立即停止，不重试、不切换传输方式、不继续远端查询；上传成功才允许一次远端核验。
不单独执行远端编号预约推送；编号在单次创建远端分支成功前视为暂定。
