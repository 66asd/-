# 双 ADC 信号测量与 page3 示波显示

目标芯片 STM32F103C8T6。ADC1/ADC2 规则组同步采样，TIM3 TRGO 硬件触发，
每路 200 kS/s，DMA1 Channel1 以 32 位循环搬运。测量范围按 100 Hz～40 kHz 设计。
显示频率、**去除直流偏置的交流有效值**和峰峰值。HMI 文件没有修改。

## 打开与接线

打开 `MDK-ARM/ADC.uvprojx`，正常 Build 后下载 `MDK-ARM/ADC/ADC.hex`。
所有 App 源文件和包含路径已加入 Keil 工程，无需手工添加。
依赖本地 CubeMX 生成的 `Drivers/`，对应 STM32Cube FW_F1 V1.8.7。

| 用途 | MCU 引脚 | 对端 |
|---|---|---|
| 信号 S1 | PA0 / ADC1_IN0 | 信号发生器 CH1 |
| 信号 S2 | PA1 / ADC2_IN1 | 信号发生器 CH2 |
| 屏串口发送 | PA9 / USART1_TX | 屏 RX |
| 屏串口接收 | PA10 / USART1_RX | 屏 TX |
| 地 | GND | 信号发生器、串口屏共地 |

串口为 115200、8N1。屏幕按其型号要求供电，串口电平须与 MCU 兼容。
模拟输入必须位于 0～VDDA；本任务的 0.6～2.7 V 适用于 VDDA=3.3 V。
先在板端确认实际幅度，避免信号发生器 50 Ω/高阻负载设置造成幅度不符。

程序不强制跳转页面，保留 HMI 原来的开机 page0 和导航操作，进入 page3 后才发送测量数据。

## CubeMX 配置与启动

- HCLK/PCLK2=72 MHz，APB1=36 MHz，TIM3 时钟=72 MHz。
- ADC 时钟 PCLK2/6=12 MHz；两个 ADC 均使用 7.5 cycles、右对齐、单通道。
- 双模式 `ADC_DUALMODE_REGSIMULT`，ADC1 触发为 TIM3 TRGO，ADC2 保留 Software Start。
- Scan、Continuous、Discontinuous 均关闭。
- TIM3 PSC=0，ARR=359，TRGO=Update Event，对应 5 μs 一次触发。
- DMA1 Channel1：外设到内存，Word/Word，内存递增，Circular；开启 DMA 与 USART1 中断。

`ScopeApp_Init()` 分别校准两个 ADC，调用 `HAL_ADCEx_MultiModeStart_DMA()`，最后启动 TIM3。
每次 DMA 搬运一对结果：低 16 位是 ADC1，高 16 位是 ADC2，各自有效位为低 12 位。
DMA 半块为 512 对数据，即 2.56 ms。中断只记录完成序号，主循环复制已完成的半块再处理。
复制期间若 DMA 越过边界，该副本作废；检测到丢块时重置统计，避免将不连续数据当作连续信号。

## 三项算法

### 频率

门限随测量得到的均值更新。信号先进入门限下方的滞回区域，再寻找向上过零点；
过零位置用相邻两个原始采样值插值。达到上方门限且至少连续两个采样值位于均值上方，
才确认该事件，从而抑制单点毛刺。使用多周期时间累计，而非只测相邻两个点的间距。
对孤立漏过零修正累计周期数；持续变化的相邻边沿间隔用于重新锁定新的频率。

统计窗口为 10000 个原始采样值，即 50 ms。无可信周期或超出测量范围时，屏上频率显示 `--`。
窄到只有一个采样点的脉冲不属于可靠频率测量对象。

### 交流有效值

\[
V_{RMS,AC}=\sqrt{E[V^2]-E[V]^2}
\]

原始数据逐点统计，累加器为 64 位。优先使用窗口内第一、最后一次确认过零之间的整周期区间；
周期不足时使用整个窗口。先在整数域减掉直流能量，再开方，减少大偏置、小交流信号下的浮点消减误差。
模块也能返回总 RMS，但 HMI 只打印用户选择的交流 RMS。

例如 0.6～2.7 V 的理想正弦波：偏置 1.65 V、VPP=2.1 V、交流 RMS≈0.742 V。

### 峰峰值 VPP

没有直接使用整段 `max-min`。

1. 对完整原始测量窗口建立 256 桶直方图，每桶同时保存数量和原始码值之和。
2. 使用 0.2% 与 99.8% 分位处桶内平均值之差作为抗异常点的统计包络 VPP。
3. 对显示采样帧执行 `DC + a*cos(wt) + b*sin(wt)` 最小二乘拟合。
   内循环使用 Q15 查表、整数乘加，分批执行；第二遍剔除残差过大的少量点。
4. 只有拟合残差足够小、剔除比例不超过 2%、频率稳定时，才认定为正弦波，
   使用 `2*sqrt(a*a+b*b)` 修正真实峰值落在采样点之间造成的漏峰。
   其他波形保持统计包络估计，不直接套用正弦波公式。

在 40 kHz、200 kS/s 时每周期只有 5 点，正弦波的采样最大/最小值可能明显低估 VPP，
拟合可以修正这一问题。包络方法会有有限的桶宽误差，也会抑制占比不足 0.2% 的极窄真实峰值。
不存在对任意波形都无损的去尖峰算法。

## 波形、自动设置与停止

- 两路使用各自的显示降采样率，支持一路 100 Hz、另一路 40 kHz；测量仍使用每路全部原始数据。
- 每路只保存 1024 个 16 位显示采样点，避免为 100 Hz 的多个周期保存过多原始数据。
- 显示持续自动跟踪约 4 个周期，上升沿对齐；纵向将 VPP 映射到约 80% 图高。
- 显示点之间做线性插值，不伪造额外的原始采样点。
- 点击“自动设置”会恢复运行并强制获取新的自动量程波形。
- 点击“停止”后冻结最后一帧波形与数值，停止提交新帧；ADC/DMA 和后台测量继续运行。
  同一按钮运行时显示“停止”，冻结后运行时文字为“继续”；再次点击恢复。
- 已进入 addt 透传的帧会完成，避免将屏卡在等待数据的状态；冻结最多延后一个在途帧。
- 屏显节流为至少 150 ms 一帧，实际刷新率取决于捕获与串口事务，串口不是 200 kS/s 的全量数据出口。

波形发送采用 `cle → addt → 等待 FE → 指定数量原始字节 → 等待 FD`。
UART 用中断发送，不在采集回调里 printf。透传超时会尝试补齐事务、重新查询页面，
不会无限等待；只有确认当前 page3 才写入该页控件。

原 HMI 中标签、按钮与波形矩形存在重叠，因此每帧结束会 `ref` 原有覆盖控件，保持按钮可见。

## 校准与限制

- 将实际测得的 VDDA 毫伏值填入 `App/scope_config.h` 的 `SCOPE_REFERENCE_MV`。
  默认 3300；ADC 上电校准不能替代参考电压和外部电路增益校准。
- 40 kHz 上限主要适用于稳定、信噪比足够的正弦波。200 kS/s 的奈奎斯特频率为 100 kHz，
  高频方波、三角波的高次谐波会混叠；不能承诺任意波形在 40 kHz 时都精确还原。
- 输入电路应按需要配置抗混叠滤波；显示插值无法补回已混叠的信息。
- 频率切换或直流偏置明显变化后，需留出若干测量/捕获窗口重新稳定。
- 未实现屏上未定义的相位数值控件；采样本身仍为双 ADC 同步方式。
