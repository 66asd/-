# 双 DDS 发生与双 ADC 同步测量

## ① 接线和首次通电

屏上按键 → USART1 → STM32 修改对应 DDS 的 RAM 设置 → 独立数字线写 DDS。两块 DDS 自己连续输出。模拟输出经调理分别进入 PA0、PA1；同一个 TIM3 更新沿触发两路 ADC，DMA 存入成对样本。屏上的设置值来自 RAM，SBQ 波形和测量值来自 ADC。

下面按 STM32F103C8T6 的端口名接线。先断电接数字线，模拟信号先接示波器。模块板的供电脚、输出放大器、跳线以及屏电平需要看实物丝印和模块原理图。

| 模块端 | MCU 或另一端 | 方向、电平与检查 |
|---|---|---|
| MCU 板 3V3、VDDA/VSSA | 稳压 3.3 V / GND | 裸芯片所有电源脚均需供电、就近去耦。最小系统板确认带 8 MHz HSE 晶体并将 BOOT0 拉低 |
| AD9833 VCC | 按模块额定电压供电
| 优先使用明确支持 3.3 V 电源和逻辑的板；5 V 模块须核对输入高阈值 |
| AD9959 模块 VIN | 按实物板额定电源接 | 核对板载 1.8 V 核心稳压及 3.3 V 数字接口，禁止直接给裸芯片核心供 5 V |
| TJC VCC | 独立稳压电源，按背标额定电压与背光电流 | 确认为 5 V 型号后接 5 V，不用 ST-Link 的 3V3 小电流引脚带屏 |

| AD9833 模块 VOUT | 调理 A → PA0 / ADC1_IN0 | 模块 → MCU，ADC 脚瞬时范围 0～VDDA，留约 0.1 V 上下余量。方波模式也要重新查最大电压 |
| AD9959 模块 CH0 OUT | 调理 B → PA1 / ADC2_IN1 | 模块 → MCU，使用板上单端电压输出。裸 IOUT/互补电流端需按板图做 I/V、终端和滤波；变压器耦合板需确认 1～2 kHz 能通过 |

| ST-Link SWCLK | PA14 | 调试器 → MCU |

**模拟输入的实际做法。** 先看示波器直流耦合读到的最低、最高电压，按最终负载测量。有些模块标称的幅度对应 50 Ω 负载，高阻输入时幅度会变化。已在允许范围内的低阻单端信号可经约 1 kΩ 串联进入 ADC。双极性输出可先衰减，再隔直流、偏置到 1.65 V。例如已确认是低阻、约 ±1 V 的单端信号，每路用 1 µF 串联到偏置节点，节点用两只 10 kΩ 分别接 3V3 与地，再用 3.3 V 轨到轨缓冲运放跟随，经小串阻进 ADC。偏置网络等效 5 kΩ，高通转折约 32 Hz。更大输入先按峰值设计分压。按实际源阻抗与带宽核算滤波；方波的高次谐波可超过 50 kHz 并混叠。首次接 MCU 前，在断开 PA0/PA1 的情况下量调理输出，两端都须落入允许范围。确认 MCU 已供电后再接回采。

**时钟和电压校准。** 固件假定 AD9833 MCLK 25 MHz，AD9959 REFCLK 25 MHz、PLL ×20、SYSCLK 500 MHz。看晶振、时钟选择及外部参考跳线，检查 AD9959 的晶体/有源时钟接法、PLL 环路滤波和允许倍频；若为直供系统时钟则设 PLL9959=1。量出频差为固定倍率时先查时钟。误差校正可修改 config.h 中的参考频率。用表量 VDDA 填 VDDA_MV，再把同一已知幅度信号接入两路，按“示波器输入端 Vpp / ADC 脚 Vpp × 1000”分别填 GAIN1_PERMILLE、GAIN2_PERMILLE。默认 1000 显示 ADC 脚电压。交流耦合偏置在计算 AC RMS 时会被扣除。

APB1 分频非 1，TIM3 内核时钟为 2 × 36 MHz。72 MHz / (0+1) / (719+1) = 100,000 次更新/s。每沿得到一对样本，间隔 10 µs，每路 100 kS/s。单 ADC 转换 (55.5+12.5)/12 MHz = 5.67 µs，两路同时转换，离下一沿尚余约 4.33 µs。

CubeMX 生成 main、spi、gpio、adc、dma、tim、usart、系统时钟和中断入口。应用在 USER CODE 区启动 DDS、采样和屏幕调度。Keil 的 DDS Application 分组保管自定义模块。AD9833 在备用寄存器组写好频率和相位后切换，调参时相位累加器持续运行。AD9959 通过一次 IO_UPDATE 同时提交 CH0 的频率、相位和幅度。

sample_start 依次执行 ADC1 校准 → ADC2 校准 → HAL_ADC_Start(&hadc2) → HAL_ADCEx_MultiModeStart_DMA(&hadc1, dma, 2048) → HAL_TIM_Base_Start(&htim3)。F1 从 ADC 配置 ADC_SOFTWARE_START，多模启用后由主 ADC 的触发驱动同步转换。DMA 的 Length 是 2048 个传输单元，每单元 32 位。取样代码等价于：

```c
uint16_t adc1 = (uint16_t)(pair & 0x0fffu);
uint16_t adc2 = (uint16_t)((pair >> 16) & 0x0fffu);
```

**如何避免混帧。** 半满/全满回调仅发布半区号和递增代数。主循环按需取最近完整半区，比较上次代数跳过旧块。复制前后各检查 DMA1_Channel1->CNDTR 判断目标半区是否正在写，再检查代数是否变化。校验通过才对快照计算。即使在复制末尾刚好跨越 DMA 边界，CNDTR 和代数也能拦截竞争。DMA IRQ 优先级最高，不能另加持续半区时间以上的关中断代码或靠调试器单步检查连续性。设置写完后重建代数基线，跳过随后两次完成事件，从第三个新完成半区开始取数。翻页不会重新启动 TIM3 或 DMA。missed_frames 包括显示主动跳过的帧；raced_frames 记录复制过程检测出的竞争。

| SRAM 分配 | 字节 |
|---|---:|
| DMA，2 × 1,024 × 4 | 8192 |
| 配对快照，1,024 × 4 | 4096 |
| 两条显示曲线，2 × 479 | 958 |
| USART RX 环、TX 命令、帧识别窗口 | 256 + 96 + 8 |
| 栈预留 / 动态堆 | 2048 / 0 |

半区完成间隔是 1024 / 100000 = 10.24 ms，20.48 ms 回到同一半区。半区完成后实际安全复制时间只有 10.24 ms。链接大小包含静态栈预留，真板栈水位需另测。

## ③ 串口屏下载与操作

打开 HMI/DualDDS.HMI，检查目标型号与屏背标 TJC4827X243_011 一致，横屏 480×272。在 USART HMI 编译，选择屏下载串口；下载时断开 MCU 对屏 RX 的驱动，USB-TTL 和屏共地、TX/RX 交叉，上传后接回 PA9/10。也可按该屏支持的方式使用已导出的 HMI/DualDDS.tft。若用 microSD，按该型号要求准备 FAT32 卡，根目录只放这一个 TFT，断电插卡，上电等下载成功，断电拔卡再上电。新版的 page2 底部有两个 Step 按钮。

| 页 | 实际控件与操作 |
|---|---|
| page0 / page1 | page0.b0/b1/b2/b3 分别进入 DAC/DDS/SBQ/SWP；page1 保留模板，返回可用 |
| page2 左半 | b0/b1 调 AD9833 频率，b12/b13 调相位，b9/b10/b11 直接选正弦、三角、方波。t3/t8/t7 显示频率、相位、波形。b14 独立选择左路频率步进 |
| page2 右半 | b2/b3 调 CH0 频率，b4/b5 调幅度比例，b6/b7 调相位。t4/t5/t6 分别显示频率、比例、相位；b15 选择右路频率步进。CH0 始终输出正弦。单位 d 表示度 |
| page3 / SBQ | s0 ID=1 为 AD9833，s1 ID=17 为 CH0。t1/t3/t5 为 S1 频率、AC RMS、Vpp；t7/t9/t11 为 S2 同三项；t13 为 S2 相对 S1 的上升沿相位。模板里的 newtxt/nwetxt 均已替换 |
| page4 / SWP | b1、b2 各自开始/停止。第一路 b3/b4 调跨度、b5/b6 调步长、b7/b8 调速度；第二路 b9/b10、b11/b12、b13/b14 对应相同三项。t11～t16 分别显示两路跨度 Hz、步长 Hz、驻留 ms |

默认 AD9833 为 1,000 Hz 三角波，AD9959 CH0 为 2,000 Hz 正弦、100%，两路相位均为 0°。每路手动频率范围 300～10,000 Hz，初始步进 100 Hz；点 Step 循环 100 → 1000 → 1 → 10 → 100 Hz。每按 Deg± 改 15°，跨过 0°/360° 环绕；当前步长可达 0°,15°,…,345°。CH0 幅度 0～100%，每按一次 5 个百分点。百分比对应 ASF 0～1023，实际输出电压由模块及负载决定。

扫频下限为该路手动设定频率，默认跨度 1000 Hz、每步 100 Hz、每步保持 200 ms。初始扫频区间分别为 1～2 kHz、2～3 kHz。跨度 ± 每次 100 Hz，上限夹到 10 kHz；步长 ± 每次 10 Hz，最小 1 Hz；速度 + 将驻留缩短 10 ms，速度 − 将驻留延长 10 ms，范围 50～2000 ms。即使步长大于跨度也先到上端点，再从下端循环。停止回到手动频率；手动改频结束本路扫频。可同时扫两路，离开 SWP 后继续。断电恢复默认，单独复位屏幕会重新同步 MCU 中的 RAM 值。

模板原先 Program.s 为 9600，部分按钮按下发送单字节，且跨页重复。新版上电 115200、bkcmd=0，各页加载完成发送 sendme。调节键释放发送 65 页号 控件ID 00 FF FF FF，例如 page2.b0（ID 8）为 65 02 08 00 FF FF FF；页回复为 66 页号 FF FF FF。接收环跨主循环保留半帧，可连续拆多帧。MCU 每 500 ms 查询页号，页变化立即取消旧绘图任务；每次最多安排一条串口命令，先收交互，再推进绘图。应用独占 USART1，调试 printf 走其他接口。

**波形与读数。** 1024 对同步原始样本共同决定两条曲线；每路求 min/max、去直流 RMS 和带滞回条件的中值上穿时间，过零时刻按相邻样本线性插值，频率由首末上穿和周期数计算。输入小于 16 个 ADC 码峰峰值或上穿不足两次时，频率显示 --。到达 ADC 满量程会削顶，幅度、相位和有效值均会失真。频率单位 Hz，AC RMS 与 Vpp 单位 V。同频条件采用相差不超过 0.5% 的门限；相位用过中点上升沿的时差，范围约 ±180°，正为 S2 超前。默认两路频率不同会显示 --。两块独立晶振会使同频相位缓慢漂移。对不同波形，相位是边沿时间定义，不等于基波傅里叶相位。

两窗口共用 S1 首个有效上升沿作横向基准；若没有触发或末端样本不足，从快照开头自由显示。水平窗约为 S1 的四周期，最多 800 对；无有效周期用 400 对。默认 4 ms 同屏正好可见约四个三角和八个正弦。第 x 列取 start+floor(x×(N−1)/478)，压缩时抽取、展开时重复最近原始点；单次窄尖峰可能漏掉。两曲线 Y 数据均为 round(ADC×104/4095)，直接送给对应的 105 像素高波形控件，坐标原点由控件处理。固定同一量程，幅度改变会反映为实际高度改变。S1 自触发会把 S1 的水平移动重新对齐；测试相位调节时让两路同频，看两波的相对位置和 t13。

115200、8N1 每秒最多 11,520 字节。单个 add 1,0,104 加三字节结束符为 14 字节，add 17,0,104 为 15 字节；479 对最多 13,891 字节，再加两条 cle、七个读数和少量页面查询，约 14.1 kB，一帧线速下限约 1.23 s。固件设 1.6 s 起帧间隔，目标约 0.625 帧/s，实测还受屏执行速度影响。画面是采样快照，屏上逐列绘制期间两路 ADC 仍各以 100 kS/s 采集。

1. 模拟回采先断开，连接 SWD。打开 DualDDS_SPI.uvprojx，Target 选 STM32F103C8，ARM Compiler 5、MicroLIB。Options → Debug 选择实物对应的 ST-Link Debugger、Port=SW；Flash Download 确认 STM32F10x Medium Density，Reset and Run。先 F7 编译，再 F8 下载。也可将 MDK-ARM/DualDDS_SPI/DualDDS_SPI.hex 用 STM32CubeProgrammer 经 ST-Link 下载。
2. 用示波器确认两块 DDS 默认输出，再查适配后的模拟端电压。若 CH0 无波，依次看 PB5 复位脉冲、REFCLK、有无 SCLK/CS、IO_UPDATE、CH0 端口和输出级低频响应。AD9833 无波则看 FSYNC、SCLK、SDATA 和 MCLK。调 CH0 幅度至 50%，同负载 Vpp 应约为原来一半。
3. 接串口屏，DDS 页逐路改频和相位、选波形，换页再回来核对数值。无响应先查供电共地、TX/RX 交叉、115200 8N1、文件版本。逻辑分析仪看到 65 02 08 00 FF FF FF 时，AD9833 应增加当前 Step 一档。
4. 先用相同的、已调理的安全正弦电压同时馈入 PA0/PA1，保持 DDS 输出端彼此独立。两路应显示同频、相近幅度、相位约 0°。用已知 1.000 Vpp 正弦检查 AC RMS 约 0.354 V，三角约 0.289 V。再分别接各自的 DDS；默认 S1、S2 应约为 1000 Hz、2000 Hz。低频失真随频率变化时检查耦合网络与终端。
5. Keil Watch 看 generation 增长，每秒约 97.66 次半区事件，DMA1_Channel1->CNDTR 在 2048～1 持续递减并重装。用运行时观察或短时外部引脚打点验证节拍，断点会破坏时序。若只见一个有效半字，重点查 ADC2 通道、从 ADC 启动、DMA 两端 Word 和 2048 长度。
6. 两个 SWP 分别设置不同跨度/步长/速度，开始后切 SBQ，连续点击返回、再进入 DDS。检查波形任务停止、设置保留、采集代数持续增加。最后拔掉电脑，用独立电源重启；默认设置应恢复，后续操作完全在屏上完成。
