# ADC 示波器固件

当前验收输入：PA0，1 kHz、1 Vpp、已有直流偏置。默认按正弦波验收，
对应交流 RMS 约 354 mV。显示的 RMS 为去除直流偏置后的交流有效值，
不是包含直流分量的总 RMS。PA1 仍保留独立测量；不用时接地，避免浮空。

## 操作与 HMI

直接使用本目录 `DualDDS2.HMI`，无需修改 HMI。已从已保存的 page3 核对：

| 控件 | ID | 行为 |
| --- | --- | --- |
| b1 自动设置 | 16 | 松开回传 `65 03 10 00 FF FF FF`；恢复绘图，重新定位时基 |
| b2 停止 | 17 | 松开回传 `65 03 11 00 FF FF FF`；当前帧绘完后冻结波形和读数 |
| s0 | 1 | PA0 波形，242×213，发送 241 个点 |
| s1 | 15 | PA1 波形，239×211，发送 238 个点 |

旧代码把 s1 当成 ID17（实际是停止按钮），并发送479点，与新HMI不匹配。
现已纠正，删除对不存在的相位文本 t13 的发送；两路削顶在对应频率标题显示 CLIP。
AUTO 以 PA0 为触发参考；PA0 无可靠频率时才参考 PA1。两路频率不同时，
3–5周期目标适用于参考通道。运行时自动跟踪时基，显示约4周期；STOP后按AUTO恢复。

## 采样与算法

- TIM3触发双ADC同时转换，DMA快照一致性检查保留；默认400 kS/s，
  自动在2–400 kS/s间调整，目标约180点/周期。10 kHz时仍有40点/周期。
- ADC时钟12 MHz，采样13.5周期，加12.5周期转换共约2.17 µs，小于2.5 µs触发间隔。
  此配置面向低阻信号发生器输出；高阻源需要缓冲或更长采样时间与更低采样率。
- 切换采样率时停止定时器、ADC和DMA，恢复HAL停止函数清掉的双ADC模式，
  重新启动并丢弃过渡帧，避免新旧采样时钟混算。
- 两路统一使用VDDA、4096和独立增益系数，去掉S2旧的原始噪声峰谷窗口。
- 频率：迟滞上升过零、亚采样插值、多过零点线性回归，排除明显不一致的周期。
- 测量：完整周期的分数边界积分计算交流RMS；同相位周期平均求一般周期波峰谷。
  仅在拟合残差足够小且未削顶时使用正弦最小二乘求幅度和RMS。
- 显示：周期叠加、插值；识别出的低失真正弦用拟合曲线显示。一般波形保留
  周期平均形状，非正弦不会强制画成正弦。测量不从屏幕像素反推。
  shortcut: 周期叠加用于稳定周期信号；突发、调制和瞬态需另设单次采集模式。

## 标定与1%指标

`Core/Inc/config.h`：

- `ADC_VDDA_CAL_MV`：默认0，使用内部参考估算VDDA。实测供电后可填入毫伏值，
  例如3287；这只是示例，不能未经测量照填。
- `ADC_VREFINT_CAL_MV`：默认典型1200 mV，允许按单板参考电压标定。
- `GAIN1_PERMILLE` / `GAIN2_PERMILLE`：默认1000，无分压/放大。可按
  `新系数 = 旧系数 × 已知实际Vpp / 显示Vpp` 修正各路增益。
- `DDS_ENABLED`：默认0，DDS驱动代码保留，设1可恢复输出功能。

STM32F103内部参考典型值不是逐片标定值，其公差本身可能超过1%。
当前没有实测VDDA或经过校准的输入标准，因此**不能承诺实板绝对误差已≤1%**。
参考：[ST数据手册](https://www.st.com/resource/en/datasheet/stm32f103v8.pdf)。
信号发生器负载设定应与实际输入一致：PA0是高阻输入，50Ω负载标注幅度与
高阻幅度可能不同；应以实际引脚电压为准。输入必须保持在0～VDDA范围内。

## 验证与下载

打开 `MDK-ARM/DualDDS_SPI.uvprojx` 编译；输出
`MDK-ARM/DualDDS_SPI/DualDDS_SPI.hex`，此任务未执行实板下载。
Keil ARMCC5编译0错误、0警告，Code19144、RO544、RW120、ZI16816字节，
RAM共16936字节（含2KB栈，无堆），低于20KB。

`python tests/verify_measure.py` 使用Unicorn直接执行最新Keil AXF中的ARM代码，
依赖numpy和unicorn。覆盖63帧双通道正弦，300 Hz～10 kHz、0.5～2.5 Vpp、
不同起始相位和3 ADC码RMS噪声，最坏频率误差0.10%、AC RMS误差0.157%、VPP误差0.20%。
还检查方波、三角波、直流、削顶、曲线范围、可见3–5周期、HMI实际ID/松开回传，
并执行固件UART解析器检查AUTO/STOP。极短初始记录无法容纳两个过零点时，
频率暂报无效，运行中的时基搜索随后降低采样率。

仿真未覆盖模拟前端、真实噪声频谱、ADC非线性、时钟误差及显示器串口执行时序。
实板验收先输入1 kHz/1 Vpp正弦，确认约1000 Hz、1000 mVpp、354 mV RMS，
点击AUTO观察约4周期，点击STOP确认整帧完成后不再滚动，再点AUTO恢复；
然后按相同幅度检查5 kHz和10 kHz。1%总误差必须用已知精度标准实测验收。
