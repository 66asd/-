# ADC 示波器固件

本次更改修复 40 kHz 后失锁、时基混叠锁定及 VPP 电压换算问题。
HMI 无需重新修改，继续使用已配置按钮事件的 `DualDDS2.HMI` / `DualDDS2.tft`。
必须重新编译/烧录 `MDK-ARM/DualDDS_SPI/DualDDS_SPI.hex` 到 STM32。

## 操作与频率范围

- page3 自动设置 b1/ID16，弹起脚本 `printh 65 03 10 00 FF FF FF`。
- 停止 b2/ID17，弹起脚本 `printh 65 03 11 00 FF FF FF`。
- s0/ID1 为 PA0（242×213，241点）；s1/ID15 为 PA1（239×211，238点）。
- AUTO 恢复运行，以 PA0 为参考显示约4周期；PA0无可靠频率才参考PA1。
  这是一次设置，之后保持显示时间窗。因此改变信号频率会改变画面周期数，
  再按 AUTO 重新调整到3–5周期。记录长度不足时显示窗口会截短。
- STOP在当前帧绘制完成后冻结波形和读数；按AUTO恢复。
- 信号采样率自动在2–600 kS/s间调整；每2秒尝试最高采样率，避免信号频率
  跳变后一直锁住低采样率下的混叠频率。低频/无信号时逐级搜索较低采样率。
  因此频率突变的重新识别可能需要一次探测及一帧串口绘制时间。
- 本次正弦数值验证范围300 Hz–100 kHz；40 kHz时15点/周期，100 kHz时6点/周期。
  接近上限时依赖稳定周期和正弦拟合。高频方波、窄脉冲及更高次谐波的幅值精度
  不在同一保证范围内；600 kS/s的奈奎斯特频率不是可保证的仪器带宽。

## 3.02 V 首次标定与定期 VREFINT 更新

旧代码只在启动时测VREFINT，并使用典型1200 mV计算VDDA，没有持续跟踪。
现采用用户提供的实测 **3020 mV** 建立单板比例标定：

1. 首次运行，在外部ADC启动前校准两个ADC，等待内部参考稳定。
   VREFINT采用239.5周期采样，丢弃切换后的前2次转换，再平均64次。
2. 把参考码总和 `S_cal` 与实测 `V_cal=3020mV` 存入独立Flash校准页。
   重启时复用有效记录，避免把后来不同的供电电压重新强定为3.02V。
3. 正常运行约每秒读取新的64次参考总和 `S_now`，使用
   `VDDA_now = V_cal * S_cal / S_now`。这同时抵消了内部参考的个体初始公差。
   低采样率时适当延长更新间隔，保证过渡帧丢弃后仍有完整记录可供显示。
4. 两路VPP和交流RMS均使用最新有效VDDA与4096换算。读取超时、参考码异常或
   算得VDDA超出2.4–3.6V时保留上次有效值，并累计 `reference_errors`。

首次标定时应保持万用表测到3.02V时的供电条件。程序并不知道首次启动时的
真实电压；如果此时电压已改变，绝对标定也会随之偏差，之后跟踪不能消除初始误差。
万用表、信号源自身的精度也计入1%总误差预算。

## 外部等间隔采样与硬件限制

TIM3触发双ADC同时转换，DMA采集。ADC时钟12 MHz，高速外部通道采样1.5周期，
加12.5周期转换和触发余量，600 kS/s间隔为1.667 µs，配置面向50Ω等低阻信号源。
高阻信号需要输入缓冲；直接照用最短采样时间可能产生额外幅度误差。

**内部参考与高速外部DMA共用ADC1，当前C8硬件无法在高速采样中无缝插入长时间
参考转换。** 本实现不采用会中断普通转换的注入方式，也不把VREF样本插入信号序列。
主循环在采集记录之间停止触发与DMA，测内部参考后恢复原外部通道、双ADC模式、
定时器和DMA；丢弃过渡帧，再发布连续等间隔的完整快照。旧、新记录不会拼接计算频率。
参考转换本身约1.4 ms（66次×21 µs），加HAL开销、重新采集和过渡帧，会有帧间死区。
**这保证每帧采样间隔，不等于全程无缝采集。** 如要求所有触发都不能漏采，需要独立的
参考监测ADC/硬件方案。软件仿真不能验证板上的真实触发间隔。

定时器改速和参考采样都会恢复HAL停止函数清除的DUALMOD。DMA拷贝前后均检查
完成代数和剩余计数，不发布正在覆盖或切换前的缓冲区。

## VPP、RMS和频率算法

- 频率使用迟滞上升过零、亚采样插值、多过零点线性回归，不再用8点阈值屏蔽40kHz附近。
- RMS为**去除直流偏置的交流RMS**，完整周期分数边界积分；1Vpp正弦约354mV RMS。
- 一般周期波采用同相位周期平均求峰谷；稳定低失真正弦通过残差检查后使用
  DC+sin+cos最小二乘求幅度与RMS，避免稀疏采样漏掉峰顶。高频也可使用该拟合。
- 显示使用周期叠加和插值，识别出的低失真正弦按拟合曲线绘制；不从显示像素计算电压。
- shortcut: 周期平均面向稳定周期波；突发、调制、瞬态需要独立的单次/实时采集模式。

`Core/Inc/config.h` 中 `GAIN1_PERMILLE` / `GAIN2_PERMILLE` 默认1000（无分压放大），
`DDS_ENABLED` 默认0，DDS代码保留。未用PA1时接地，避免浮空。
输入含偏置后的峰谷必须位于0～VDDA内；触轨时对应标题显示CLIP，不能靠算法修复削顶。
信号发生器负载设为高阻或核实实际引脚幅值，不能把50Ω标注幅值直接当成高阻输入幅值。

## 持久校准页与验证

Keil IROM已限制为 `0x08000000..0x0800FBFF`（63KB），预留最后1KB
`0x0800FC00..0x0800FFFF`存校准。首次仅向空白记录写入，校验和与最后写入的标记
防止不完整记录被使用。运行时不写Flash，也不会自动擦除未知的非空记录。
`reference_store_errors`非零说明未能持久保存，当前启动仍使用RAM中的标定。

普通代码更新应保留校准页。若要重新标定，先确认当前VDDA并更新配置，再明确擦除
校准页；整片擦除也会丢失标定，下次启动将按配置的3020mV重新校准。

`python tests/verify_adc_scope.py` 使用Unicorn执行最新Keil AXF中的实际ARM代码。
覆盖108帧双通道带噪正弦、300Hz–100kHz、0.5–2.5Vpp、多个起始相位、3码RMS噪声；
最坏频率误差0.01%、AC RMS误差0.157%、VPP误差0.20%。Keil编译0错误、0警告，
Code20160、RO544、RW160、ZI16856字节，RAM共17016字节（含2KB栈）。
并检查方波/三角波、直流、削顶、一次AUTO时基、2.7/3.02/3.3V电压换算。
参考测量的HAL外设调用由模型替代，验证首次持久化、重启复用、定期更新顺序、
超时/坏码恢复、定时器范围、DMA过渡隔离及重新探测高频。

仿真不包含真实ADC非线性、参考温漂、输入阻抗、接地噪声、晶振误差或屏幕执行时序。
实板仍需分别在1/10/40/60/80/100kHz，用已知精度的实际引脚幅值验收≤1%总误差。
参考资料：[ST数据手册](https://www.st.com/resource/en/datasheet/stm32f103r8.pdf)，
[ST参考手册RM0008](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-advanced-arm-based-32-bit-mcus-stmicroelectronics.pdf)。
